# План виконання ЛР2 Lockbox

Омельченко Богдан Юрійович, ІО-32. Робота продовжує локальний main 9d6190a після дозволеного fast-forward ЛР1. origin/main на початку залишався 2480d25; remote main не змінювався.

10 змістовних комітів: вимоги/pinout; шари/схема; IMU; ADC/PIR/планування; кнопка/калібрування; тривоги/UART; host tests/CI; записи/декодування; інтеграційні виправлення/приймання; фінальна документація/звіт.

Докази отримуємо лише власним запуском. MuseGuard є прикладом повноти, його код, протокол і записи не використовуємо. У Lockbox немає TILT, SPI-flash, камери, механічного замка чи мережі. Обсяг спирається на власний PRD та форму B.

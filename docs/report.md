# Лабораторна робота №1. Lockbox

Омельченко Богдан Юрійович, ІО-32. Форма B, без фізичної плати. Чернетка від 24.09.2026. Поки немає запуску в Wokwi, скриншотів, відео та PDF.

## Мета

Я готую середовище, у якому можна зібрати прошивку STM32 HAL і запустити її у Wokwi. Для першої перевірки достатньо побачити повідомлення через UART та блимання LED. Датчики Lockbox підключатиму в наступній лабораторній.

## Що зроблено

Вибрав STM32C031C6 для симулятора. У методичці наведені F411RE та F446RE, але в переліку STM32, які підтримує Wokwi, їх немає. З викладачем заміну плати ще не погодив.

У репозиторії є конфігурація `firmware/lockbox.ioc`, код на HAL, Dockerfile, Makefile і схема Wokwi. USART2 використовує PA2/PA3, LED — PA5. I²C1 налаштований на PB8/PB9, але датчика на схемі поки немає. Коміт з прошивкою: `c0dc0dc`.

Команда `make build` на Mac створила `lockbox.elf`, `lockbox.hex` і `lockbox.bin`. Я також склонував гілку `feature/lab01-setup` у чисту тимчасову папку без `firmware/build` і повторив збірку. Вона завершилася без помилок; [лог чистого клону](evidence/build-clean-clone.log) збережено в репозиторії. Це підтверджує збірку, але ще не роботу UART чи LED у симуляторі.

Для здачі через PR створені `main` і `feature/lab01-setup`. Обидві гілки завантажено до [lilbodyn/Lockbox](https://github.com/lilbodyn/Lockbox) 25.09.2026. PR ще не створено. Репозиторій зараз публічний, хоча методичка вимагає приватний.

## Що ще треба перевірити

| Перевірка | Стан |
|---|---|
| Збірка з чистого локального клону | Пройшла 24.09.2026. |
| Збірка у Ubuntu VM | Не виконана: VM недоступна через SSH на момент перевірки. |
| UART та LED у Wokwi | Не виконана: розширення VS Code просить ліцензійний ключ. |
| Pinout і Clock Configuration у CubeMX | Не перевірені: окремий STM32CubeMX встановлено на Mac, але файл `.ioc` у ньому ще не відкрито. CubeIDE його не знайшов. |
| Відео на 2–3 хвилини та PDF | Не підготовлені. |

Це робочі нотатки, а не п'ять розв'язаних проблем. У фінальному звіті опишу лише ті труднощі, для яких встановлю причину та зможу показати виправлення. Сюди ж додам скриншоти CubeMX і Wokwi, посилання на коміти та відео.

# Діагностичний профіль задач Lockbox

Це окрема інструментована копія, а не ELF сценаріїв S1–S3. База Git `c7772714dc56b76673fc95899836ef2ba1ec4253`; ідентифікатор вихідного коду основних вимірювань `484fae964f8e7cb1`, SHA-256 основного ELF `591c0ee8923ab6f66ceacc4acad3c561a040eec68663a281db92708c3abaa2a1`. Діагностичний ELF `firmware/build/lockbox.elf` має SHA-256 `16fa8699a281f0980540091255bb4e9f94365290a1b8a8df196785e3e719cd33`; HEX SHA-256 `b2d51ca9ac521a956045826e81ae568105eeabf5c6d58bef9c0a3fc0a68ec597`. Банер діагностичного ELF: `source=diag-cpu-only`. Бінарні файли не замінюють основну прошивку.

`diagnostic.patch` описує різницю файлів runtime.c і serial.c від бази; їхні точні копії також збережені в `firmware/Board/`. `build_version.h` є згенерованим заголовком цієї збірки, не частиною патча. `manifest.json` містить оригінальні хеші файлів конфігурації, колектора, змінених джерел та бінарників. Точний процес вимірювання не є відтворенням S1–S3.

`diagram.json` і `wokwi.toml` — фактична конфігурація Wokwi; TASK = PA6, SAMPLE = PA7, STORE = PB1. `collect.py` — фактичний host-колектор і план команд, `commands.jsonl` — фактичні host-мітки відправлення, `uart.raw` — захоплені байти після підключення. Host-час не використано як модельний час. `wokwi.vcd.gz` містить оригінальний VCD (SHA-256 розпакованих байтів `eda5ac41d0d5e37a944fb4a38a2d01c55fbdd056baa871c8d9adf37785852c21`), з початковим BOOT та фронтами. `measured.json` — аналіз саме цієї траси; у вікні без імпульсів максимум STORE не визначений.

Для повторення аналізу з Python 3, без запуску симулятора:

```sh
gzip -dc wokwi.vcd.gz > wokwi.vcd
python3 analyze_profile.py wokwi.vcd --output measured-repeat.json
```

Вікна визначаються фронтами декодованого UART: від 2 с до секунди перед ARMING і від першого до останнього з 24 заголовків journal. У цих вікнах TASK становить відповідно 9.823865% за 27.628517 с і 11.942654% за 11.499917 с. Це час позначених foreground-ділянок разом із периферійними очікуваннями та перериваннями всередині них. Порожні перевірки, переривання поза маркером і час передачі UART після повернення не враховані; вимірювальний код змінює час виконання. Значення не є повною утилізацією CPU, не є результатом S2/S3 і не доводять фізичний WCET.

# Lockbox

Навчальний проєкт Омельченка Богдана Юрійовича, ІО-32, з курсу «Системне програмування вбудованих систем».

Ідея: шафка з речами, яка помічає рух поруч, зміну освітленості всередині та струс корпусу. Зараз готова основа для ЛР1: STM32C031C6, STM32 HAL, UART і блимання вбудованого LED. Датчики та логіка охорони ще не реалізовані.

## Збірка

Потрібні Docker і `make`. У корені проєкту виконайте:

```sh
make build
```

Команда створить `firmware/build/lockbox.elf`, `lockbox.hex` і `lockbox.bin`. `make clean` видаляє згенеровані файли. У Ubuntu VM потрібен запущений Docker Engine і право користувача запускати `docker`. Збірка не потребує фізичної плати.

## Запуск у Wokwi

Відкрийте **цю папку** у VS Code з розширенням Wokwi і запустіть `Wokwi: Start Simulator`. Файл `wokwi.toml` вказує на зібрані ELF та HEX. У UART має з'явитися `Lockbox ready`, далі — `tick` щосекунди; LED на PA5 має блимати. Якщо збираєте у VM, а Wokwi запускаєте на хості, використовуйте спільну папку або скопіюйте з VM папку `firmware/build` назад у цю саму копію проєкту.

Модель C031C6 обрана тому, що вона підтримується Wokwi. У методичці згадані F411RE/F446RE; цю розбіжність ще треба погодити з викладачем. UART підключений до PA2/PA3. I²C1 налаштований на PB8/PB9, але датчиків на схемі поки немає.
